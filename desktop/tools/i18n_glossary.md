## 5. 各語言排版慣例（照抄 App 風格）

- **zh-TW / zh-CN**：全形標點「（）：／」、全形逗號。
- **fr**：冒號前為窄不斷行空格（U+202F 或 U+00A0），引號用 « »。
- **ru / uk**：引號用 « »。
- **ar**：阿拉伯逗號 «،»، 問號 «؟»；數字用西阿拉伯數字。
- **ja / ko / th / vi**：依各自慣例；ja 用「」、ko 用 ( )。
- 一律**不要**在 UI 標籤結尾加句號。
