## 5. Typesetting conventions per language (copy the App style)

- **zh-TW / zh-CN**: full-width punctuation "（）：／", full-width commas.
- **fr**: a narrow no-break space before the colon (U+202F or U+00A0); quotation marks use « ».
- **ru / uk**: quotation marks use « ».
- **ar**: Arabic comma «،», question mark «؟»; digits use Western Arabic numerals.
- **ja / ko / th / vi**: follow each language's own conventions; ja uses 「」, ko uses ( ).
- **Never** add a period at the end of a UI label.
