# Ring Audit — End-to-End Proof That a Third-Party App Can Deliver to DebugReceiver

> 中文版：[ring_reachability_test_2026-09-13.txt](ring_reachability_test_2026-09-13.txt)

**Date**: 2026-09-13 15:45 · **Purpose**: to upgrade the §2 R4 claim in `reports/ring_capture_security_audit_2026-09-13.md`
that "any installed app can send" from a manifest inference to an **end-to-end measurement**.

**Devices under test**
| Role | Serial | Model |
|------|------|------|
| Phone (app: `com.rokid.rc.phone`) | `<PHONE_SERIAL>` | 21091116UG (Xiaomi) |
| Glasses (app: `com.rokid.rc.glasses`) | `<DEVICE_SERIAL>` | RG-glasses (RV101) |

**Test app**: `com.ringaudit.reachtest` (`build-cache/ringtest/`, 8.6 KB, self-signed)
- It has a single Activity whose `onCreate` sends two **read-only** broadcasts:
  - Phone side: `com.rokid.rc.phone/.DebugReceiver` + `cmd=TEST_RING_TEXT` (pure string comparison, no side effects)
  - Glasses side: `com.rokid.rc.glasses/.DebugReceiver` + `cmd=RING_STATUS` (only prints status, no side effects)
- It did **not** send any command with side effects (`CAPTURE_PHOTO`/`START_VIDEO`/`ACQUIRE_ROOT`/`PAIR_RING`/`WIFI_ADB`/`SET_*`/`DELETE_MEDIA`).
- Build: `aapt2 link` → `javac` → `d8` → `jar uf` → `zipalign` → `apksigner` (Linux SDK 34.0.0 + the workspace `jdk`).

**Result: both succeeded** — the broadcast was sent by an **ordinary app uid** (not shell's 2000) and was executed.

## 4. Cleanup

The test app has been removed from both devices (`adb uninstall com.ringaudit.reachtest` → `Success`,

## 5. Reproduction

```bash
cd /home/kali/rokid_root/build-cache/ringtest
export JAVA_HOME=/home/kali/jdk; export PATH="$JAVA_HOME/bin:$PATH"
BT=/home/kali/android-sdk/build-tools/34.0.0
AJ=/home/kali/android-sdk/platforms/android-34/android.jar
mkdir -p out/classes out/dex
javac -source 8 -target 8 -bootclasspath "$AJ" -d out/classes $(find src -name '*.java')
"$BT/d8" --release --lib "$AJ" --min-api 24 --output out/dex out/classes/com/ringaudit/reachtest/*.class
"$BT/aapt2" link -o out/base.apk --manifest AndroidManifest.xml -I "$AJ" --min-sdk-version 24 --target-sdk-version 33
cp out/base.apk out/app-unsigned.apk && ( cd out && cp dex/classes.dex . && "$JAVA_HOME/bin/jar" uf app-unsigned.apk classes.dex )
"$BT/zipalign" -f -p 4 out/app-unsigned.apk out/app-aligned.apk
"$BT/apksigner" sign --ks out/ringtest.keystore --ks-pass pass:android --key-pass pass:android \
    --out out/app-signed.apk out/app-aligned.apk
ADB="/mnt/c/Users/<USER>/AppData/Local/Android/Sdk/platform-tools/adb.exe"
"$ADB" -s <PHONE_SERIAL> install -r out/app-signed.apk
"$ADB" -s <PHONE_SERIAL> shell 'logcat -c; am start -n com.ringaudit.reachtest/.MainActivity; sleep 4; logcat -d -s RingReachTest:* -s DebugReceiver:*'
```
