## 1. 逐列實機證據

### 1.1 CVE-2026-21385 — KGSL align sign-extension →「userland 無法控制 align」 ✅ 真

- `test_gpumem`（GPUMEM_ALLOC，align 0–255）：**全部 `errno=95 (ENOTSUP)`** → GPUMEM_ALLOC 功能禁用。
- `test_align`（GPUOBJ_ALLOC，align 0–26）：**全部 `errno=22 (EINVAL)`** → GPUOBJ_ALLOC 未註冊。
- `test_import`（GPUOBJ_IMPORT，align 0–255）：全部成功但配合逆向分析（`REVERSE_ANALYSIS_1.22_009.md` §9.3：import 依 size 強制覆寫 align）→ userland 值無效。
- **結論**：可注入 align 的三條 ioctl 路徑 = ENOTSUP / EINVAL / 強制覆寫 → userland 無法控制 align 到達 `kgsl_iommu_get_gpuaddr`。✅

### 1.2 CVE-2026-KGSL-UAF — KGSL syncsource →「SYNCSOURCE ioctl 返回 ENOTTY」 ✅ 真

- `test_sync_errno`：`CREATE: r=-1 errno=25(Inappropriate ioctl for device)` → **ENOTTY**。
- `kgsl_syncuaf_probe`：`iterations=200000, fence succ=0, errors=200000, No crash`。
- **結論**：SYNCSOURCE_CREATE/FENCE 未註冊（ENOTTY），不可達。✅

### 1.3 CVE-2024-36971 — 路由表 (dst) UAF →「loopback DST 永不 obsolete」 ✅ 真（環境性）

- `ip route` 與 `ip -6 route`：**皆為空**（無任何路由表條目）。
- 介面：僅 `lo`（127.0.0.1/8）UP 且有 inet；`wlan0` NO-CARRIER/DOWN；`dummy0` NOARP（僅 link-local v6）；無外部網路。
- `cve_2024_36971_poc`：連續輸出 `connect: Network is unreachable`（無法建立 socket 連線，`__dst_negative_advice()` 觸發條件不存在）。
- **結論**：無路由 + 無 ICMP 觸發面 → UAF 在本環境不可觸發。✅

### 1.4 CVE-2024-0582 — io_uring PBUF_RING UAF →「PBUF_RING 功能不存在（需 5.19+）」 ✅ 真

- `cve_2024_0582_mmap_uaf`：`io_uring fd=3, features=0x7ff`；`REGISTER_PBUF_RING (opcode=22) failed: Invalid argument (errno=22)`。
  - `features=0x7ff` = bit0–10 全開，**bit11 (`IORING_FEAT_PBUF_RING`=0x800) 未置位** → 功能旗標不存在。
- `cve_2024_0582_uaf_check`：`PROVIDE_BUFFERS → res=-22`、`REMOVE_BUFFERS → res=-22`。
- **結論**：io_uring 本身存在（`CONFIG_IO_URING=y`），但 PBUF_RING（5.19 引入，commit `c7fb19428d67`）在 5.10.209 不存在。✅

### 1.5 CVE-2024-38401 — KGSL UAF →「已修補」 ✅ 真

- `security_patch = 2024-07-05` → 涵蓋 2024-06 Qualcomm/Android 修補。
- syncsource（本 CVE 觸發面）在本設備回 ENOTTY（見 1.2），攻擊面同時不可達。
- **結論**：補丁時點 + 觸發面封閉雙重成立。✅

### 1.6 CVE-2025-21479 / 21480 — KGSL UAF →「Context 創建被阻止」 ✅ 真

- `gpu_context_bypass_dyn`：**31 種 context flag 組合（GL/VK/CL/…/zero flags）全部 `errno=22 (EINVAL)`**，`Total: 0/31 successful`。
  - `GPU_COMMAND (ctx=0/-1)` → `errno=19 (ENODEV)`；`GPUOBJ Alloc` → `Invalid argument`。
- **kernel dmesg**：`kgsl kgsl-3d0: legacy context switch not supported`（本次觸發產生）。
- 模組符號：`msm_kgsl.ko` 含 `a6xx_hwsched_*`（硬體排程器模式）。
- **結論**：context 創建被完全阻止，micronode/命令提交路徑不可達。✅

### 1.7 CVE-2024-43047 / 49848 — FastRPC UAF →「需經 HWBinder 取得 fd，shell 無權限」 ✅ 真

- 節點權限：`/dev/adsprpc-smd` = `crw-rw-r-- 1 system system`（0664）；`/dev/adsprpc-smd-secure` = `crw-r--r--`（0644）。
- `test_adsp`：`open O_RDWR failed: Permission denied`；`open O_RDONLY ok`。
- `id`：shell 不在 `system` 群組。
- **結論**：shell 無法直接取得可寫 fd（UAF 觸發需 O_RDWR），需經 `IDspService` HWBinder（shell 無權限）。✅

### 1.8 CVE-2023-2163 — BPF verifier →「已修補」 ✅ 真

- `cve_2023_2163_probe`：`unprivileged_bpf_disabled=0`（BPF 可用），但 PROBE 1–7 全部 `[OK] Patched: Verifier rejected`；`PROBE 6 (CVE-2023-2163 Exact Pattern) → rejected by verifier`。
- **結論**：verifier 已修補（5.10.179+ 已 backport）。✅

### 1.9 CVE-2022-0847 — Dirty Pipe →「已修補」 ✅ 真

- `dirtypipe_test_dyn`：對唯讀檔（`-r--r--r--`）`splice succeeded` + `write succeeded (4 bytes)`，但 **檔案內容未變**（前後皆 `AAAAAAAAAAAAAAAA`，offset 4 未被 `XXXX` 覆寫）。
- 版本：5.10.209 > 修復版 5.10.102。
- **結論**：Dirty Pipe 原語不成立 → 已修補。✅

### 1.10 CVE-2019-2215 — Binder UAF →「已修補」 ✅ 真

- `security_patch = 2024-07-05` 遠晚於 2019-12 修補。
- **結論**：已修補。✅

### 1.11 CVE-2021-22555 — Netfilter x_tables →「需 CAP_NET_ADMIN」 ✅ 真（且更強）

- `CapEff = 0`（無任何有效能力，含 CAP_NET_ADMIN）；`CapBnd = 0xc0`（無 CAP_NET_ADMIN）。
- 實機 config：`CONFIG_NETFILTER_XTABLES=y`（x_tables 存在）但 **`CONFIG_USER_NS is not set`**、**`CONFIG_SYSVIPC is not set`**（斷絕 user-ns 提權與 msg_msg spray）。
- **結論**：觸發需 CAP_NET_ADMIN（setsockopt `IPT_SO_SET_REPLACE`），當前 shell 無法取得。✅

### 1.12 CVE-2024-56720 — BPF sockmap UAF →「CONFIG_BPF_STREAM_PARSER 未啟用」 ✅ 真

- 實機 `/proc/config.gz`：`# CONFIG_BPF_STREAM_PARSER is not set`。
- **結論**：sockmap 前提功能未編譯。✅

### 1.13 CVE-2024-1086 / 26581 — nf_tables UAF →「CONFIG_NF_TABLES 未啟用」 ✅ 真

- 實機 `/proc/config.gz`：`# CONFIG_NF_TABLES is not set`（`CONFIG_NETFILTER=y`、`CONFIG_NETFILTER_XTABLES=y` 仍開）。
- **結論**：nf_tables 未編譯進核心。✅

### 1.14 CVE-2025-21655 — io_uring eventfd UAF →「僅影響 6.1+」 ✅ 真

- 核心 `5.10.209` < 6.1（`io_eventfd_signal()` 缺陷自 6.1 才存在）。
- **結論**：版本不在受影響範圍。✅

### 1.15 KGSL Cross-FD 訪問 — GPU 記憶體隔離繞過 →「資訊洩漏/記憶體損壞，但無法直達 kernel slab」 ✅ 真

- `kgsl_mmap_probe_dyn`：**Cross-FD mmap 成功**——FD2 讀到 FD1 緩衝區的測試樣式 `data=0xcafebabedeadbeef`（資訊洩漏成立）；較大緩衝區 cross-FD 回 EINVAL（受限）。
- dmesg：`arm-smmu 3da0000.kgsl-smmu`、`kgsl-iommu gfx3d_user / gfx3d_secure Adding to iommu group` → GPU 記憶體在 IOMMU/SMMU 之後，與 kernel slab（kmalloc）不同配置路徑。
- **結論**：cross-FD 洩漏/破壞為真，但無法直達 kernel slab。✅
